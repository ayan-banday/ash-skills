# Where the first draft goes wrong

Read before writing the first card, then check the draft against each line before publishing. The background critic checks these first. **When the critic finds a new kind of mistake, add it here as one line, dated,** so the next first draft avoids it. Fix the cause in the rule, not just the one deck.

## Ash's input

- **The note repeated back.** A card restates what Ash said instead of building on it. His note sets the A point; the cards write his best version of it and take him past it. No card summarises the note (Ash, 2026-11-10).
- **His thinking lowballed.** A rough or wrong line in the note becomes the A point as written, so he reads a weaker version of himself. Write what a smart operator meant (Ash, 2026-11-10).
- **Coverage over insight.** The deck walks through every question in the note one by one. Pick the one chunk that makes the others easy; include a detail only when it serves that chunk (Ash, 2026-11-10).
- **His specifics dropped.** The note named real people, deadlines or choices, and the deck went generic. The real moment (his one hire, his campus, his week) is what makes the question and world cards land.

## Cards

- **Thin first two cards.** The question card in two lines and the promise in one leave half the screen empty (Ash, 2026-11-10). See article-format, "The first two cards are full".
- **A picture and its words disagree.** The drawing says "day 9", the lines say "next week" (ticket 39). Read every label against the lines under it.
- **The drawing shows the wrong thing.** A scooter drawn as a bicycle (ticket 39). Name what each shape is before drawing it.
- **The far card teaches a different principle.** The far field shows something true but not the deck's cause and effect (ticket 39). Its last line states the same principle in the far field's words.
- **A number with no sum.** "₹55,000" with nothing that makes it (ticket 39). Every number shows where it came from on the same card.
- **A heading that isn't Ash's plain question.** "If it comes" instead of "Will it come?" (ticket 39).
- **Hedging lines.** "No speech. No values poster." (ticket 39). Cut any line that says what something isn't.
- **A card that points back.** "the same draft", "like the kid". Read each card with the others hidden.
- **The metaphor is the same activity in another job.** It must be a daily-life scene from a world nothing like the problem's (teach-side-chat's metaphor check).
