The short answer

Ash keeps one master copy of each skill in a single repo, packed into five plugins named for the job: write, visual, plan, build and learn. What is a Claude Code plugin, in plain words?

A plugin is a box of skills that a project installs in one step. The skills live once, inside the box, and every project that installs it gets the same version.

  1. The crate is the plugin: one folder, named for its job, here visual.

  2. The sheets are the skills inside it. Each is a folder with an instructions file, the same skills Ash uses today.

  3. The tag is plugin.json, a small file with the plugin's name and version, so Claude Code knows what it installed.

  4. The shelf is the marketplace: a list in Ash's repo of every crate on offer. A project picks the crates it wants.

What changes for you: you type /visual:brief-page where Ash types /brief-page-udyaan today. The word before the colon is the plugin's name.
