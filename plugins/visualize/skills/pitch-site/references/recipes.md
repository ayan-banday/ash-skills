# Recipes: make every build look different

Two proposals from this skill should never look like siblings. Each build combines four choices, and the combination
is logged so the next build differs.

## Contents
- The four choices
- Recipes that read differently
- The build log

## The four choices

1. **Architecture** (how the page is read): `scroll` (one long vertical page with colour blocks), `paged` (a paper deck,
   one sheet at a time), `horizontal` (a scroll painting that unrolls sideways). Shells are in `assets/architectures/`.
2. **Direction** (what it is made of): one of the 20 in `references/directions/`, or a new one derived from the client's world.
3. **Signature move** (the one orchestrated moment): pick one starred entry, for example the pinned stage with an
   x-ray (SEQ-02, STR-25), the snake (SEQ-01), construction lines to a finished drawing (SEQ-03), the switchboard
   (STR-02), the pull-back (STR-26), the motif that builds strand by strand, the build-up that folds into the ask.
4. **The close**: three pictured steps and a person (PPL-28), the motif returning finished with an approval box,
   a decision slip with the pick already circled (PPL-29), every thread ending at one name.

## Recipes that read differently

- **Threshold** (proven: TVS). Scroll + kolam + snake and constellation; close with three pictured steps and a drawn
  portrait. For a partnership with a South Indian institution.
- **Engineering drawing** (proven: Coastline prototype). Scroll + drafting + one pinned stage that x-rays the client's
  own object and pulls back onto a real map; asks hang off the drawing by leader lines; close with the drawing
  returning finished and an empty PILOT ROUTE cell circled. For manufacturing, logistics, hardware.
- **Front page.** Paged + letterpress: each sheet is a newspaper front page about one ask (a heavy headline, ruled
  columns, a boxed "stop press" for what the reader gets); the last sheet is the special edition with the decision.
  For institutions, boards, public bodies.
- **Specimen plates.** Paged + herbarium: each sheet is one plate (a pressed plant drawn in sepia line, numbered detail
  circles for the capabilities, a label slip with the ask). For agriculture, food, health, research.
- **The procession.** Horizontal + Warli: the client's day as a band of figures walking left to right, each ask a
  scene on the wall, one continuous ground line under them. For cooperatives, communities, NGOs.
- **The line.** Horizontal + transit map: three coloured lines (the asks) run across the track, stations are the
  teams, the interchange is the pilot; the rail at the bottom is the line itself. For logistics, multi-site programmes.
- **The tile.** Scroll + azulejo: four tiles meet to form one flower as the asks resolve; each section adds a tile.
  For hospitality, food and beverage, real estate.
- **The overprint.** Paged + risograph: each sheet prints one colour pass; by the last sheet the full picture has
  registered. For media, youth, creative and student-facing work.
Combine differently when the brief asks for it; these are starting points.

## The build log

After publishing, append one line to `references/builds-log.md` in this skill: date, client, architecture,
direction, signature move, close, artifact link. Before choosing for a new build, read the last five lines and
change at least two of the four choices from the previous build (unless Ash asks for the same look).
